Read `s38`'s raw markup directly in `05 Portfolio and Wallet.dc.html`: header
titled "Receipt" with a back icon (`nav.s35`, the wallet home) and a trailing

in `lib/screens/wallet/wallet_screens.dart`, not `contract_note_screen.dart`.**
`TransactionDetailScreen` already matches it near line-for-line (its own
comments cite each row, including the "Fees, all in" single figure and the

single "Fees, all in" figure doesn't carry at all. No artboard in the
current 56-artboard canvas covers that content; `s52` ("Statements and
contract notes", `06 Account and Support.dc.html`) is only the *list* of
statements/notes (confirmed from its raw markup — row labels like "Contract
note · MTNN buy"), not a note's own itemised detail view.

**No code fix was needed.** Both files already carry this exact resolution

this screen's real content," and `wallet_screens.dart`'s says

known-stale. Nothing in `lib/` mis-cites `s38` today.

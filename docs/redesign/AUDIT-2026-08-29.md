## What failed in verification

Three layers, each of which looked like verification and was not.

1. **Screens were certified by the agents that built them.** Every
   "matches the artboard, element by element" claim in this redesign came from the
   same agent that had just written the screen, reading its own render. That is a
   model grading its own homework — the exact failure this project's gate harness
   was built to prevent, reproduced one level up.

2. **No independent design-conformance pass ever ran.** 188 screenshots were
   produced and nobody systematically compared them to the artboards. The
   comparison was delegated, not performed.

3. **The live gate asserts absence, not capability.** "No `KErrorView` is present"
   answers *did it crash*, not *can the user do the thing*. A dead sign-up field
   and a release APK with no network permission both passed it.

## What that means for the fixes below

Nothing in this file gets marked done on an agent's own say-so. Each item needs
either a rendered image compared against its artboard **by an agent that did not
build it**, or a flow walked end to end.
